# AI Learning Digest Feed

Public, machine-readable AI learning briefings for an iPhone Shortcut. This repository contains public news summaries and source links only. It must never contain contact information, personal notes, private documents, or API keys.

`latest.json` is the current payload. `kind` is `test`, `daily`, or `weekly`; `date_bjt` is the content date in Asia/Shanghai. The iPhone Shortcut should check both before sending a scheduled briefing. A `test` payload is for manual delivery checks only.
